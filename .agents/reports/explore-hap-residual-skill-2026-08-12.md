### When to load

Load `.agents/skills/lean4/SKILL.md` when a residual Name or plan slice primarily
touches `src/systems/**/*.lean` or Lake proofs. Do **not** invent Open Names to
exercise the skill.

### Workflow pick (HostCost / Nat cost)

| Situation | Skill workflow | Project constraint |
|-----------|----------------|--------------------|
| New HostCost claim + skeleton + proof together | **formalize** (`/lean4:formalize`) | Statements are the API; do not rewrite theorem headers to finish green |
| Informal cost claim to declaration only | **draft** | Then prove; keep Nat vs ns honesty in the header |
| Fill remaining sorries (interactive) | **prove** | Lake / `just systems-host` still decide Done when |
| Unattended sorry fill with budget | **autoprove** | Stop when stuck; no claim-bool flips from greps |
| Refute a bad cost equality | **disprove** | Adds a counterexample theorem; does not rewrite the original |
| Lake / instance / timeout | **doctor** | Then compilation-error refs |
| Before calling a Name done | **review** (read-only) | Does not replace `just check` / `lake build SystemsLean.HostCost` |
| Proof heavy but correct | **refactor** then optional **golf** | Golf is **proof** performance, not freestanding wall-clock |
| Checkpoint | **checkpoint** | **No agent git commit**; human signs |

Typical residual loop: Name/Goal/Done when -> load skill if `.lean` -> red/green
project gates first (`just systems-host`, focused lake) -> skill for
declaration/proof -> gates for done -> residual / WATCHER / handoff lockstep.

### Skill does not replace

- Inventing residual
- Growing shell or hand-authored product C
- Forging freestanding / PROVABLY / FullHost
- Agent commits (project AGENTS wins over upstream checkpoint-commit advice)
- Pure Nix policy mills
- Emit SSOT (`src/systems/emit/host-owned-emit.md`)

HostCost formalize target is **Nat step equalities and shape lemmas** (mint,
consume, check, extract fuse, cap bounds). It is **not** a theorem that mint
is faster than heap_churn in nanoseconds.
