# Agent plan hygiene

**Kind:** process detail. Standing law: project `AGENTS.md` subsection **Never overwrite a living plan**.

## Overwrite story (operator 2026-09-19)

A living plan is still the plan. Session `plan.md` and living project plans under `.agents/plans/` are not scratch pads. Replacing the whole file because a later agent only read a prefix, or because a new `/implement` block looks tidier, drops remaining bullets, decisions, and Done when lines the operator already approved.

That overwrite is the miss. The later text is not more true just because it is newer.

## How to revise

1. Read the **whole** file before any edit. A short prefix is not the plan.
2. Revise by **dated addendum**. Keep the old body. Add a dated section that states what landed, what is superseded, and what is still live.
3. Mark each old remaining bullet **done**, **superseded**, or **still live**. Do not delete unmarked leftovers.
4. If the operator says **add this to the last plan**, **append**. Do not write a full replacement.
5. Do not treat repeating an identical `/implement` status block as progress (low time preference). Finish the named job.

## What this is not

This file does not move maximally nice builds (`nice -n 19`, idle ionice). That rule stays in `AGENTS.md` under **Lake host and niceness**.
